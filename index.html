La evolución del software

Evolución del software: cinco generaciones, desde el código máquina hasta la inteligencia artificial.

Elaboró: Brandon Alvis

1940 – 1955

PRIMEROS PROGRAMAS

Primeros programas (1940–1955)

  • Programación directamente en lenguaje máquina.
  • Uso de código binario: 0 y 1.
  • Programar era lento, complejo y propenso a errores.
  • Los programas dependían completamente del hardware.
  • Konrad Zuse — Pionero de la computación; desarrolló una de las primeras computadoras programables y creó el lenguaje Plankalkül.
  • Ejemplos: ENIAC, EDVAC, UNIVAC I.

1955–1970

LENGUAJES DE ALTO NIVEL

Lenguajes de alto nivel (1955–1970)

  • Aparecen lenguajes como FORTRAN y COBOL.
  • La programación se vuelve más sencilla y legible.
  • Surgen los primeros sistemas operativos.
  • Se utilizan compiladores para traducir los programas.
  • Grace Hopper — Impulsó el desarrollo de compiladores y ayudó a crear COBOL, haciendo la programación más accesible.
  • El software comienza a utilizarse en ciencia y empresas.
1970 – 1999

SOFTWARE PERSONAL

Computación personal (1970–1999))

  • Aparecen los microprocesadores y computadoras personales.
  • El software deja de estar limitado a grandes instituciones.
  • Se popularizan sistemas operativos como MS-DOS y Windows.
  • Surgen lenguajes como C, C++ y BASIC.
  • Bill Gates — Figura clave en la popularización del software para computadoras personales a través de Microsoft.
  • Crecen los videojuegos y las aplicaciones de escritorio.
1970 – 1999
1999 – 2010
1999 – 2010

INTERNET Y SOFTWARE WEB

Internet y aplicaciones web (1999–2010)

  • Internet transforma la forma de crear y distribuir software.
  • Aparecen páginas y aplicaciones web.
  • HTML, JavaScript, Java y PHP ganan popularidad.
  • Se desarrollan buscadores, redes sociales y comercio electrónico.
  • Tim Berners-Lee — Inventor de la World Wide Web, fundamental para la evolución del software hacia Internet.
  • El software comienza a funcionar cada vez más conectado.
2010 – Actualidad

NUBE, MÓVILES E INTELIGENCIA ARTIFICIAL

Software moderno (2010–ACTUALIDAD)

  • Aplicaciones móviles y servicios basados en la nube.
  • Desarrollo con metodologías ágiles y DevOps.
  • Uso de grandes cantidades de datos.
  • Inteligencia artificial y aprendizaje automático.
  • Sam Altman — Figura destacada en el desarrollo y popularización de la inteligencia artificial generativa, impulsando herramientas capaces de comprender y crear contenido.
  • RIA generativa capaz de crear texto, imágenes y código.
1982 – Actualidad
